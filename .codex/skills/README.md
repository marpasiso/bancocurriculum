# Skills locais opcionais

Deixe esta pasta vazia enquanto as skills globais atenderem ao projeto.

Crie uma skill local somente quando o projeto possuir um fluxo recorrente e específico que não deva afetar outros repositórios, por exemplo:

- validação própria de migrations;
- geração de contrato de API específico;
- auditoria de multi-tenancy do sistema;
- processo particular de release;
- convenções exclusivas de UI ou domínio.

Não copie automaticamente as skills globais para cá. Isso evita versões duplicadas e divergentes.
